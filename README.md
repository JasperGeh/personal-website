# Jasper Götting's Personal Website

This is the repository for my personal website, built with just HTML and CSS, and the help of Claude Opus 4.5.

It is hosted on GitHub Pages and can be viewed at [jaspergoetting.fyi](https://jaspergoetting.fyi/).

To preview locally, run 
```bash
python3 -m http.server 8000
```
then visit `http://localhost:8000`.
